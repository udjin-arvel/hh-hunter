# Политика конфиденциальности HH-Hunter

**Версия:** 1.1.0  
**Дата:** 2026

## Кратко

HH-Hunter — расширение для браузера Chrome. Оно помогает составлять сопроводительные письма к вакансиям HeadHunter. Расширение **не собирает** персональные данные на собственных серверах: профиль и настройки хранятся локально в вашем браузере.

## Что хранится локально

В `chrome.storage.local` сохраняются:

- имя и текст профиля (достижения, навыки);
- ссылка на портфолио;
- настройки генерации (стиль, длина, фокус).

API-ключ DeepSeek **не вводится пользователем** — генерация выполняется через встроенную интеграцию расширения.

## Куда отправляются данные

### DeepSeek API (`api.deepseek.com`)

При нажатии «Сгенерировать» на сервер DeepSeek отправляются:

- имя кандидата;
- текст опыта и достижений;
- описание вакансии и ключевые навыки;
- параметры стиля и длины письма.

Запрос выполняется от имени расширения. Политика обработки данных DeepSeek: [https://www.deepseek.com](https://www.deepseek.com).

### HeadHunter API (`api.hh.ru`)

Для загрузки вакансии выполняется публичный запрос `GET /vacancies/{id}` без авторизации. Передаётся только идентификатор вакансии из URL, который вы указали.

### Импорт портфолио (опционально)

Если вы указываете ссылку на портфолио и нажимаете «Импортировать», расширение запрашивает HTML-страницу по этому URL. Запрос идёт напрямую с вашего браузера. Если сайт блокирует запрос, вы можете ввести текст вручную.

## Права расширения

| Право | Зачем |
| :--- | :--- |
| `storage` | Локальное сохранение профиля и настроек |
| `sidePanel` | Панель расширения |
| `activeTab`, `tabs` | Работа с вкладкой HH.ru |
| `api.hh.ru`, `api.deepseek.com` | Загрузка вакансии и генерация |
| `https://*/*`, `http://*/*` (опционально) | Импорт портфолио по URL пользователя |

## Безопасность

- В консоли расширения не выводятся промпты и текст профиля.
- Расширение не добавляет стороннюю аналитику.

## Удаление данных

Удалите расширение в `chrome://extensions` или очистите данные сайта расширения — локальное хранилище будет удалено.

## Контакты

Вопросы по конфиденциальности: укажите контакт репозитория проекта в описании Chrome Web Store.
