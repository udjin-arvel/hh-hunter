# Acceptance checklist — HH-Hunter 1.1.0

Чек-лист по разделу 8 [hh-hunter.tech-spec.md](hh-hunter.tech-spec.md) и релизным критериям итерации 8.

## Функциональность

### 1. Импорт портфолио сохраняется локально

- [ ] Открыть вкладку «Профиль»
- [ ] Указать валидный URL портфолио (или использовать тестовую страницу)
- [ ] Нажать «Импортировать» — текст появляется в «Достижения и навыки»
- [ ] Нажать «Сохранить профиль», перезагрузить side panel — данные на месте

### 2. Парсинг HH URL (все вариации)

- [ ] `https://hh.ru/vacancy/12345678`
- [ ] `https://spb.hh.ru/vacancy/12345678`
- [ ] URL с `#` и query-параметрами
- [ ] На вкладке «Генератор» вакансия загружается по ID

### 3. Дефолты формы генерации

- [ ] Стиль: «Деловой» (`business`); доступны «Разгов.» / «Деловой» / «Цифры»
- [ ] Длина: «Среднее» (`medium`)

### 4. Генерация менее 20 секунд

- [ ] Заполнены профиль (≥100 символов) и вакансия
- [ ] «Сгенерировать» — результат появляется < 20 с (ручная проверка)

### 5. Три блока результата

- [ ] После генерации видны: скрытые ключи, точка пересечения, письмо

### 6. Уникальность письма

- [ ] Письмо не копирует дословно требования вакансии (ручная оценка тональности/уникальности)

### 7. Копирование только текста письма

- [ ] «Скопировать» — в буфере только текст письма, без JSON и служебных блоков

## Платформы и сборка

### 8. Chrome + Edge smoke

- [ ] Chrome: side panel, импорт вакансии, генерация, копирование
- [ ] Edge (Chromium): те же сценарии

### 9. `make check` проходит

- [x] `make check` — typecheck, lint, test, build без ошибок

### 10. `make zip` — валидный ZIP

- [x] `make zip` создаёт архив в `.output/`
- [x] ZIP содержит `manifest.json` с версией `1.1.0`

## Приватность и permissions

- [x] На вкладке «Профиль» отображается блок конфиденциальности
- [x] В консоли расширения нет промптов и текста профиля (аудит кода)
- [x] Permissions не расширены сверх `storage`, `activeTab`, `sidePanel`, `tabs` и заявленных host

## Примечания

Ручные пункты (4, 6, 8) отмечаются после smoke-теста в браузере.

Автоматические пункты (9, 10) проверяются командой:

```bash
make check
make zip
```
