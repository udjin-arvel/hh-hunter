# Chrome Web Store — метаданные HH-Hunter

## Название

HH-Hunter

## Краткое описание (до 132 символов)

Персонализированные сопроводительные письма для вакансий HeadHunter с помощью DeepSeek. Профиль хранится локально.

## Полное описание

HH-Hunter — расширение для соискателей на HeadHunter. Откройте вакансию, загрузите её в боковую панель и сгенерируйте уникальное сопроводительное письмо на основе вашего опыта.

**Возможности:**

- импорт вакансии по ссылке с hh.ru;
- профиль с достижениями и опциональным импортом портфолио;
- настройка стиля и длины письма;
- три блока результата: скрытые ключи, точка пересечения, готовое письмо;
- копирование письма и переход к отклику на HH.

**Конфиденциальность:** профиль хранится локально в браузере. При генерации данные отправляются в DeepSeek API. Подробности — в PRIVACY.md.

Собственный API-ключ DeepSeek не требуется.

## Обоснование permissions

| Permission | Justification |
| :--- | :--- |
| `storage` | Сохранение профиля и настроек локально |
| `sidePanel` | Интерфейс расширения в боковой панели Chrome |
| `activeTab`, `tabs` | Определение активной вкладки с вакансией HH |
| `https://api.hh.ru/*` | Публичный API для загрузки данных вакансии |
| `https://api.deepseek.com/*` | Генерация текста письма через DeepSeek |
| `https://*/*`, `http://*/*` (optional) | Импорт текста портфолио по URL, указанному пользователем |
